Text Rendering & Fonts

Nativ renders text by rasterizing glyphs into GPU textures and drawing them with the same textured-quad pipeline used for solid rectangles. Two font pipelines are supported:

  • Bitmap fonts — a built-in 7x13 fixed-width font, zero setup
  • TrueType / OpenType fonts — any TTF/OTF file, at any size, rasterized per glyph by golang.org/x/image/font/opentype

Default font

Labels and buttons use basicfont.Face7x13 unless a custom Font is assigned. It covers ASCII 32–126 and needs no setup:

label := widget.NewLabel("Hello") // renders with the built-in 7x13 font

Loading a custom font

Use the top-level nativ package to load a TTF/OTF font from a file or from an in-memory []byte. The size is in pixels at 72 DPI.

Using a custom font

Assign the returned *Font to a widget's Font field. Different fonts and different sizes create separate cached atlases.

custom, err := nativ.LoadFont("C:\\Windows\\Fonts\\segoeui.ttf", 16)
if err != nil {
    log.Fatal(err) // widget falls back to the default 7x13 font if nil
}

big, err := nativ.LoadFont("C:\\Windows\\Fonts\\segoeui.ttf", 24)
if err != nil {
    log.Fatal(err)
}

title := widget.NewLabel("Heading")
title.Font = big

body := widget.NewLabel("Body text in Segoe UI")
body.Font = custom

btn := widget.NewButton("OK")
btn.Font = custom

Embedding a font

import "embed"

//go:embed assets/Roboto.ttf
var robotoData []byte

func main() {
    roboto, _ := nativ.LoadFontFromData(robotoData, 14)
    // ...
}

How it works

Each unique Font+size pair gets a lazily-built glyph atlas the first time it is drawn. Glyphs are rasterized to an alpha mask, uploaded once to the GPU, and cached for the lifetime of the process. The fragment shader samples the atlas .r channel as the alpha value so glyphs composite correctly over any background color.

DrawCommand text

Text is emitted as renderer.DrawCommand values with the Text and Font fields set (see the API Reference). Solid-colored quads and text share one draw call pipeline, batched by font.
