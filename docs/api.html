type Font

type Font struct { /* unexported */ }

An immutable font (parsed TTF/OTF plus a pixel size). Create one with LoadFont or LoadFontFromData, then assign it to a widget's Font field. See Text Rendering & Fonts.

type BoxLayout

func NewVBoxLayout() *BoxLayout

Vertical box layout (children stacked top-to-bottom).

func NewHBoxLayout() *BoxLayout

Horizontal box layout (children stacked left-to-right).

func (l *BoxLayout) Add(w Widget) func (l *BoxLayout) Remove(w Widget) func (l *BoxLayout) Children() []Widget

Children are sized evenly within the available space, minus padding (10) and spacing (8) between children. Layout recalculates when bounds change or children are added/removed. Events dispatch to children in reverse order (topmost child first).

Package renderer

type DrawCommand

type DrawCommand struct { X, Y, Width, Height float32 R, G, B, A float32 Text string Font *Font // nil means the default 7x13 font }

A rectangle to render: either a solid quad (empty Text) or text glyphs drawn at (X, Y) in the given color. Coordinates are in window pixel space, origin at top-left.

type Renderer

type Renderer interface { Init(platform.Platform, width, height int) error Draw([]DrawCommand) error Shutdown() error SetSize(width, height int) }

SetSize is called by the window on resize events so the viewport matches the window's pixel dimensions.
